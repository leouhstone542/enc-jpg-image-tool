## What Is ENC to JPG Converter?

ENC to JPG Converter is a browser utility for recovering JPG images from supported encrypted `.enc` files. It offers a simple workflow for image collections that require decryption before use, including files originating from WhatsApp backup-related workflows.

All conversion work takes place in the browser instead of through a remote upload service. Users can provide a password, select from the available decryption methods, and process files individually or in batches. Where the source format permits it, the conversion retains image quality.

- Turn compatible encrypted `.enc` image files into JPG images

- Handle several files during one batch conversion
- Import files by dragging them into the upload area
- Retain image quality where supported by the conversion process

## Converting Files

1. Visit ENC to JPG Converter with a supported browser.
2. Drop one or more `.enc` files onto the input area, or select them with the file chooser.
3. Provide the password used by the encrypted files.
4. Pick the decryption method that corresponds to the files.
5. Begin the conversion process.
6. Download or save the generated JPG images locally.

To use batch conversion, select all required files before starting. The application will process the chosen files together in the same browser session.

## Frequently Asked Questions

### What kind of ENC files are supported?

The converter is intended for supported encrypted `.enc` files containing image data that can be converted to JPG.

### Does the application upload my files?

No remote upload is part of the intended workflow. Selected files are processed in the browser rather than uploaded to or stored by the conversion tool.

### Is batch conversion available?

Yes. Select multiple supported files and start the batch workflow to process them in one session.

### Why is my password rejected?

Check that the password belongs to the selected encrypted files. You should also verify that the chosen decryption method matches their source. An incorrect password or incompatible method may stop the conversion.

### Can I use it on different operating systems?

Yes, provided the platform has a compatible modern web browser. The application is browser-based rather than tied to one operating system.
